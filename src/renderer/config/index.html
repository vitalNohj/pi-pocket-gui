Billion-context Pi

                        

                            
Context compression for Pi Pocket's agent: it folds finished parts of a long conversation into short summaries and can open them again, so a conversation goes on far past the model's context window. A Pi Pocket extension, from billion-context-pi-pocket-adapter.

  1. 
                                        On the server (Linux or macOS), put its files in Pi Pocket's extensions folder. The same command updates it:
                                        
    
                                            
                                            
                                        
    
                                    
    2. 
                                    
  2. If Pi Pocket keeps its data somewhere other than ~/.pi-pocket, change the path in the command. On Windows, download the repository and copy billion-context-pi-pocket-adapter.ts and the billion-context-pi-pocket-adapter folder there.
    3. 
                                    
  3. In Pi Pocket, open Menu → Extensions and turn on billion-context-pi-pocket-adapter. To update, turn it off first, run the command, and turn it on again.

This computer as a runner

                        

                            
A Pi Pocket server can run a session's tools on this computer: its files and commands here, with the agent, its models, and its keys on the server. The app runs the runner for you while it is open. Only you can start, see, and prompt sessions on this computer; nobody else on the server can.

                            

                                Not linked
                                
                                    
                                    
                                
                            

                            
                            

                                
To link this computer: open the server in this app, then Menu → Computers → Link a computer → Link this computer. It takes one click; the app installs what the runner needs.

                            

                            

                                Another computer, such as a server
                                
    
                                    
  1. In Pi Pocket, open Menu → Computers → Link a computer, name it, and choose Link another computer (or Make a link code in a browser). It shows a one-time code, good for 10 minutes.
    2. 
                                    
  2. 
                                        On that computer, with Node.js 22.19 or newer, install Pi Pocket:
                                        
    
                                            npm install -g https://codeload.github.com/vitalNohj/pi-pocket/tar.gz/live-0.28
                                            
                                        
    
                                    
    3. 
                                    
  3. 
                                        Link it with the code, using the server's address as that computer reaches it:
                                        
    
                                            pi-pocket runner link https://your-server CODE
                                            
                                        
    
                                    
    4. 
                                    
  4. 
                                        Keep it running. On Linux with systemd, as a service that starts with the computer:
                                        
    
                                            pi-pocket runner service
                                            
                                        
    
                                        Anywhere else, in a terminal that stays open: pi-pocket runner. It connects out to the server, so that computer needs no open port.
