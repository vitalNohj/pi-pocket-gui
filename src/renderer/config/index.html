Or get the server yourself

This app connects to a Pi Pocket server that already runs. Install one on this computer or on another one, start it, then put its address above.

  1. Install and start it (Node.js 22.19 or newer):
    npm install -g pi-pocket && pi-pocket
  2. Choose This device only in its menu, then use the address it shows (http://127.0.0.1:8787 by default).
  3. Open its login link once in this app to sign in.
