                                Link another computer
                                
    
                                    
  1. In Pi Pocket, open Menu → Runners → Link a computer. Name the computer and choose Link another computer (or Make a link code in a browser). The code expires after 10 minutes.
    2. 
                                    
  2. On that computer, install Node.js 22.19 or newer. Then install Pi Pocket:
    npm install -g https://codeload.github.com/vitalNohj/pi-pocket/tar.gz/live-0.28
    3. 
                                    
  3. Run this command. Enter the server address and link code when asked:
    pi-pocket runner serve
    On Linux, it offers to start as a service at login. Run it again to use the saved link. No open port is needed.
    4.

Billion contextKeep long conversations going with context compression.

                        

                            
This extension summarizes older messages. Pi can read the originals when needed. About this extension

                            
                            
Ideally, only agents, meaning long-running sessions, would use billion-context, and regular sessions would not. Pi Pocket does not separate agents from sessions yet, and that is a big feature to add, so this app turns the extension on for all sessions, which is how I use it. I hope Pi Pocket adds an "Agents" feature where agents use this extension for their compaction and regular sessions do not. PiP, Pi Pocket's assistant, is an agent that should get billion-context.
